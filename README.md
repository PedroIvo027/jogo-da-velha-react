# Jogo da Velha

Projeto desenvolvido utilizando React para praticar conceitos fundamentais da biblioteca.

## Tecnologias

- React
- JavaScript
- HTML
- CSS
- Vite

## Funcionalidades

- Alternância entre jogadores
- Verificação de vencedor
- Histórico de jogadas
- Navegação entre jogadas

## Como executar

```bash
npm install
npm run dev
